### 👋 About me

Applied AI & Backend Engineer Intern at **Top Speech Health**, final-year student at **IIIT Allahabad** (ECE, B.Tech).

I build production speech-AI systems on GCP — real-time audio analysis with Gemini, Cloud Functions/Cloud Run services, and Firestore-backed data pipelines serving paying users internationally.

- 🔭 **Currently:** hardening a clinical speech-assessment pipeline (Gemini + Praat + FFT) into a paid production tool
- 📱 **Also shipped:** a native iOS therapy app (Swift/SwiftUI) with a live paying subscriber base
- 🧩 **400+** DSA problems solved across LeetCode and GeeksforGeeks
- 🌱 **Independent research:** trained/evaluated Wav2Vec2 speech models (PyTorch, Hugging Face)
- 💬 **Ask me about:** speech AI, GCP serverless, audio DSP, or React
